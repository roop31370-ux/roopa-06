# MERN MySQL Authentication System

## 📌 Project Description
This is a full-stack authentication system built using:
- React (Frontend)
- Node.js + Express (Backend)
- MySQL (Database)

It supports:
- User Registration
- Login with JWT Authentication
- Protected Routes
- Forgot Password
- Reset Password

---

## 🚀 Features
- Secure password hashing using bcrypt
- JWT-based authentication
- Protected API routes
- Full CRUD operations
- Responsive UI (React)

---

## 🛠️ Technologies Used
- React.js
- Node.js
- Express.js
- MySQL
- Axios
- JWT
- bcrypt
